Approximate TPU Implementation in Verilog

Implementation of a 16x16 Approximate Tensor Processing Unit (APTPU) in Verilog

View on GitHub
README.md

Exact TPU computation demands high area and power due to full-precision MAC units. The APTPU addresses this by replacing exact PEs with Approximate Processing Elements (APEs) fed by Pre-Approximate Units (PAUs) that compress operands before computation. This separation of steering logic from arithmetic logic reduces critical path delay, area, and power while maintaining acceptable inference accuracy for error-tolerant deep learning workloads.
